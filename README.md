# 昼中華3連単

火・水・木に店長が食べるお昼を当てる、社内向けの予想ゲームです。

- 画面：GitHub Pages（このリポジトリのファイル）
- データ：Google スプレッドシート ＋ Apps Script（`gas/Code.gs`）
- 写真：Google ドライブ

---

## はじめに準備すること（1回だけ・15分ほど）

### 1. スプレッドシートとApps Scriptを用意する

1. Google ドライブで **新しいスプレッドシート** を作り、名前を「昼中華3連単」にします。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このリポジトリの `gas/Code.gs` の中身を全部貼り付けて **保存**（💾）します。
4. 左の ⚙️ **プロジェクトの設定** → **タイムゾーン** を「(GMT+09:00) 日本標準時 - 東京」にします。
5. エディタに戻り、上の関数の選択欄で **`初期設定`** を選んで **▶ 実行** します。
   - 「承認が必要です」→ 自分のアカウントを選ぶ →「このアプリは Google で確認されていません」と出たら **詳細 → （安全ではないページ）に移動** → **許可**
   - スプレッドシートに「設定・参加者・週・メニュー・結果・予想・獲得pt・ログ」のシートができ、ドライブに「昼中華3連単の写真」フォルダができれば成功です。

### 2. Apps Scriptをウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ**
2. 歯車 ⚙️ → **ウェブアプリ**
3. 次のように設定して **デプロイ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーします。

### 3. GitHub に置く

1. GitHub で **New repository** → 名前 `hiru-chuka-sanrentan` → **Public** → **Create repository**
   - 無料プランの GitHub Pages は Public リポジトリが必要です。公開されるのは画面のプログラムだけで、予想やptなどのデータはスプレッドシートにあり、外からは見えません。
2. 手元でこのフォルダの `config.js` を開き、`API_URL: ''` の `''` の中に、手順2でコピーしたURLを貼って保存します。

   ```js
   window.CONFIG = {
     API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
   };
   ```
3. リポジトリの画面で **uploading an existing file** を押し、このフォルダの中身（`index.html`・`app.js`・`assets` フォルダなど全部）をドラッグして **Commit changes**。
4. **Settings → Pages** → Source を **Deploy from a branch**、Branch を **main / (root)** にして **Save**。
5. 数分後、`https://（あなたのGitHubユーザー名）.github.io/hiru-chuka-sanrentan/` で開けるようになります。このURLを参加者に伝えてください。

### 4. 自分をホストにする

1. アプリを開いて「はじめての方はこちら」から登録します。
2. スプレッドシートの **参加者** シートで、自分の行の **ホスト** にチェックを入れます。
3. アプリを開き直すと「ホスト」タブが出ます。ほかのホストも同じようにチェックで増やせます。

## 毎週の流れ

| いつ | だれ | やること |
|---|---|---|
| 月曜 | ホスト | ホストタブでメニューを人気の順に並べ、締切を決めて「出馬表を公開する」 |
| 火曜の締切まで | みんな | 予想タブで火・水・木を1つずつ選び、使うptを入れて決定（締切までは何度でも変更可） |
| 火〜木 | ホスト | 締切後、ホストタブでその日に食べたものを選び、写真を付けて「発表する」。メニュー外や休みの日は「中止にする」 |
| 木曜 | ホスト | 3日分そろったら「結果を確定する」→ ptが計算されて結果タブに出ます |

## ptのしくみ

- 最初の持ち点は全員 10,000pt（設定シートで変えられます）
- 日替わりpt：当たった日ごとに **使うpt × 1/3 × その品のオッズ**（端数切り捨て）
- 3連単：3日とも当たれば、さらに **使うpt × 3品のオッズのかけ算**
- 中止の日がある週は、使ったptを全額返します（当たり・はずれの記録だけ残ります）
- オッズは人気順で決まります（設定シートの「オッズ1〜8」「9番人気以降の増分」で調整できます）

## よくある作業

- **ptの補充**：参加者シートの「補充pt」に足したい数を入れます（例：5000）。すぐ持ち点に反映されます。
- **持ち点の計算**：初期持ち点 ＋ 補充pt ＋ これまでの獲得pt − これまでに使ったpt
- **パスワードを忘れた人**：参加者シートのその人の行を消すと、同じニックネームで登録し直せます（それまでの記録はなくなります）。
- **Apps Script を書き換えたとき**：**デプロイ → デプロイを管理 → ✏️ 編集 → バージョン「新バージョン」→ デプロイ**。URLは変わりません。

## 注意

- スプレッドシートの持ち主（オーナー）は、全員の予想を見られます。
- 写真はドライブの「昼中華3連単の写真」フォルダに入り、リンクを知っている人が見られる設定になります。
- シェアボタンを押すと、結果の画像がコピーされます。スマホやSlackのバージョンによって貼り付けられない場合は「画像を保存」してから投稿してください。
